# 웹 페이지 (index.html)

결과물 폴더의 파일 묶음이 그대로 페이지 한 벌이 된다. 들어가는 문은 `index.html`이다.

## 모양

- **파일 하나가 기본.** `<style>`과 `<script>`를 `index.html` 안에 넣는다. 그림이 꼭 필요하면 옆에 나란히 두고 `<img src="map.png">`처럼 상대 경로로 잇는다.
- 하위 폴더(`assets/…`)는 쓸 수 없다. 파일 이름에 `/`를 넣지 않는다. 파일은 100개까지.
- 맨 위에 `<!doctype html>`, `<meta charset="utf-8">`, `<meta name="viewport" content="width=device-width, initial-scale=1">`을 둔다. `<title>`은 페이지의 제목.
- 폰에서 먼저 본다: 한 줄로 읽히게 쌓고, 넓은 화면에서만 나란히 놓는다. 표는 가로로 밀 수 있게 감싼다.
- 글꼴은 시스템 글꼴을 쓴다 (`font-family: system-ui, -apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`). 글꼴 파일을 받아 넣지 않는다.
- 바깥 스크립트 · 스타일(CDN)에 기대지 않는다. 꼭 필요하면 페이지가 그것 없이도 읽히게 만든다.
- 장소가 둘 이상 나오는 답(코스 · 맛집 · 여행)이나 지도를 달라는 지시는 [map.md](map.md)의 본보기로 약도를 넣는다. 약도도 바깥 지도 없이 페이지 안에서 CSS로 그린다.

## 페이지가 열리는 곳

페이지는 격리되어 열린다 (다른 출처로 취급된다).

- 쿠키 · `localStorage` · `sessionStorage`는 쓸 수 없다. 상태는 메모리에만 둔다.
- 이 서버의 API를 부를 수 없다. 페이지에 넣을 내용은 만들 때 다 넣는다.
- 바깥 링크는 `target="_blank" rel="noopener"`로 새 창에서 연다.

## 내용

- 지시가 물은 것에 먼저 답한다. 맨 위에 한두 줄 요약, 그 아래에 자세한 내용.
- 최신 정보는 웹 검색으로 확인한다. 가게 이름 · 주소 · 여는 시간 · 가격은 확인한 것만 적고, **확인한 곳의 주소와 확인한 날짜**를 페이지 아래에 모아 적는다.
- 확인하지 못한 것은 "확인 필요"라고 적는다. 지어내지 않는다.
- 사람의 연락처 · 주소 같은 개인 정보를 넣지 않는다.

## 확인

- `python3 -c "import html.parser"`로 따로 검사하지 않아도 된다. 대신 파일을 다시 읽어 닫히지 않은 태그, 빈 링크, 깨진 상대 경로가 없는지 본다.
- 결과물 폴더에 `index.html`이 있는지 마지막에 한 번 더 본다.
- 답(마지막 메시지)에는 무엇을 만들었는지, 확인한 출처가 몇 곳인지, 확인하지 못한 것을 적는다.
