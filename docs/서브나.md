# Cairn 2차: 서브 나

> 2차 버전 설계 (2026-11-14 확정). 1차(기획서 10장 1~7단계와 그 뒤)에서 만든 재료 위에 쌓는다.
> 결정의 이유는 [기획서](기획서.md) 12장, 단계의 상태는 기획서 10장. 서버 브라우저는 [브라우저](브라우저.md).
> 화면 시안: https://claude.ai/artifact/RdLcYhZNJnSXVdmyN79y6k (대화 · 폰 · 결과물 · 블로그 · 어시스턴트 · 자동화 · 러너)

## 1. 목적과 다섯 가지 목표

**어디서든 나를 돕는 "서브 나".** 나는 목적을 말하고 결과를 결재만 한다. 일은 서버의 AI 팀이 AI끼리 나눠서 하고, 모든 것은 내 서버 한곳에 남는다.

| # | 목표 | 됐다고 말할 수 있는 때 |
|---|---|---|
| 1 | 내 컴퓨터와 서버가 MCP로 협력해 병렬로 빨리 끝낸다 | Claude Code에서 한 번 맡기면 팀이 서버에서 동시에 일하고, 세션은 묶이지 않고 소식 · 결과를 받는다 |
| 2 | 서버 브라우저로 사이트에서 목적을 이룬다 | 등록한 사이트에서 AI가 양식을 채우고, 결재 뒤 제출까지 되고, 화면 캡처가 남는다 |
| 3 | 모든 AI 작업이 한곳에 모인다 | Claude Code 세션 · 웹 AI 대화 · 서버에서 한 일이 말하지 않아도 서버에 쌓인다 |
| 4 | 글과 결과물을 모아 종류별로 보고, 골라서 블로그로 내보낸다 | 보관함 한 화면에서 결과물 · 읽은 글 · 세션 · 위키를 거르고, 블로그 메뉴로 공개한다 |
| 5 | 새 AI 도구가 나오면 붙여서 자란다 | 새 MCP 도구 · 모델 · CLI를 결재 한 번으로 붙이고, maintainer가 붙일 거리를 PR로 올린다 |

**나에게 오는 것** (콘솔 · 폰에서만. 기기 · AI는 결재하지 못한다):

| 오는 것 | 언제 |
|---|---|
| **결과 결재** | 대화의 일이 끝났을 때. 결과물 · 동작을 골라 승인하면 고른 것만 남고 실행된다 |
| 로그인 필요 | 서버 브라우저가 로그인 화면을 만났을 때. 콘솔 화면에서 로그인하면 이어서 한다 |
| 한도에 닿음 | 회차 · 시간 · 토큰 한도. 그때까지의 최선 결과로 결과 결재가 온다 |
| 도구 붙이기 · 머지 · 배포 | 5번 목표의 결과 결재 (새 도구, maintainer의 PR) |

일하는 도중의 결재 · 질문은 없다. 팀원은 정해서 진행하고 **가정한 것**을 남긴다. 대표가 모을 때 확인하고 결과 카드에 보인다.

## 3. 화면

**① 홈**: Claude 홈과 같은 모양. 인사 · 입력 하나 · `+`(파일 · 결과물 · 사이트 붙이기) · 프로젝트 고르기 · 팀(대표) 고르기 · 최근 결과물 카드 · 진행 중 대화 · "나에게 온 것" 수.

**② 대화**: 상대는 늘 대표 하나.
- 팀 카드: 팀원별 한 줄(리서처 · 분석가 · 제작자 · 브라우저 담당 · 검토자)과 상태(진행 · 완료 · 대기). 펼치면 팀원의 일.
- 팀이 일하는 중에도 보낸다(덧붙이기). 대표가 바로 답할 수 있으면 답하고, 아니면 다음 회차에 반영한다.
- 끝나면 결론 · 근거 · 남은 일 + 결과 결재 카드.
- 같은 대화가 MCP로도 열린다: `ask_agent`에 상대를 생략하면 대표, 답 · 소식은 `agent_updates`(훅 · 상태 줄 · 스킬 `cairn-team`, 세션을 묶지 않는다). 결재는 콘솔 주소만 알린다.

**③ 보관함**: 결과물 · 읽은 웹 글 · 블로그 글 · 세션 · 위키를 한 화면에서, 종류 · 프로젝트로 거른다.

**④ 메뉴**: 어시스턴트 · 자동화 · 러너 · 브라우저 · 블로그 · 지식 · 설정. 대화가 만든 것을 보고 다듬는 곳이다. 대화로 바꾼 설정은 내 말이면 바로, AI의 제안이면 결과 결재로.

## 4. 대화와 AI 팀

| 역할 | 하는 일 |
|---|---|
| 대표 | 받을 것에서 거꾸로 계획하고 나눠 맡긴다. 모아서 결론을 쓰고 결과 결재를 올린다 |
| 실행 담당 | 리서처(웹 검색 · `read_url`) · 분석가 · 제작자(샌드박스, HTML) · 브라우저 담당(서버 브라우저) · 코드 담당 |
| 검토자 | 기준표로 점수를 매기고 반론한다. 만든 쪽과 다른 도구(Claude ↔ Codex) |
| 판정 | 받을 것의 검사. 하네스와 서버가 한다 (AI의 "다 됐다"는 주장이다) |

- **상태판**: 대화마다 목표 · 받을 것 · 정한 것 · 가정한 것 · 시도 기록. 메시지는 종류(제안 · 반론 · 결정 · 가정 · 결과)를 단다.
- **소식**: 팀원 끝남 · 중간 보고 · 가정 · 최종 결과. 내 세션은 훅(말을 걸 때마다) + 상태 줄로 받는다. 채널(push)은 켤 수 있을 때.
- **멈춤**: 대화마다 한도(기본 회차 10 · 2시간 · 토큰). 점수가 두 번 연속 오르지 않으면 최선안으로 결과 결재를 올린다.
- **퍼지지 않게**: AI의 말은 서로에게 자료다. 지시는 내가 쓴 말뿐이다. 내 세션(기기)의 말은 기기의 말로 남아 `read_url`의 기준을 넓히지 않는다.

## 5. 결과 결재와 받을 것

대화를 시작할 때 끝에 받을 것 하나를 정한다. 기본은 세션 · 대표가 요청을 보고 고르고, 세부 모양(보고서 · 표 · 발표 · 지도)과 가는 길은 AI가 정한다.

| 받을 것 | 어디까지 | 검사 |
|---|---|---|
| HTML | 보관함 | `index.html`, 필수 구성, 근거의 출처 링크 |
| 블로그 | 메뉴에 올리고 공개 대기 | 메뉴 · 편집 방침 · 쓴 재료 표시 |
| 브라우저 동작 | 마지막 클릭 직전 | 허용 출처 안에서만 움직였는지, 결재된 클릭이 준비됐는지 |
| 코드 (저장소 프로젝트) | `cairn/<작업>` 브랜치 | `pnpm check` · 테스트 |
| (안 정함) 대화 답 | 말풍선 | 없음 |

**결과 결재 카드**: 항목(결과물 · 동작)마다 고르는 칸, 수정 요청 메모, 승인(고른 개수) · 수정 요청 · 반려.
- 승인: 고른 결과물은 보관함에 남고 고르지 않은 것은 휴지통으로. 고른 동작은 실행한다 (발행은 서버가, 브라우저 제출은 결재된 클릭으로).
- 수정 요청: 메모가 대표에게 가고 같은 대화의 다음 회차로.
- 반려: 모두 거절.

## 6. 러너와 하네스

| 러너 | 셸 | AI가 도는 동안 바깥 | 맡는 일 |
|---|---|---|---|
| 일반 러너 (서버, 동시 N, 기본 3) | 없음 | 일반 인터넷 + 서버 브라우저 | 조사 · 글 · 대화 · 검토 · 브라우저 일 |
| 샌드박스 러너 (서버, 칸 하나에 일 하나) | 있음 | 모델 API + 서버만 | 코드 · 만들기 · 페이지 고치기 |
| maintainer (샌드박스 한 종류) | 있음 | 따로 망 · 허용 목록 | Cairn 자신 · CLI · 스킬 · 확장의 최신화. PR까지 |
| 내 컴퓨터 러너 (선택) | 없음 | 내 네트워크 | 묶인 에이전트의 일만. 내 폴더 복사본 |

- 하네스: ① 빌리기 → ② 준비(AI 없음) → ③ AI → ④ 끝(검사 · push · 결과물 · 기억 메모 · 제출, AI 없음) → ⑤ 치우기.
- 셸과 자유로운 인터넷을 한 러너에 두지 않는다. 셸과 비공개도. 비밀은 하네스 메모리에만. 결과는 서버에 두고 내 세션이 가져간다.
- 화면 이름 "칸"은 "샌드박스"로 바꾼다.

## 7. 서버 브라우저: AI 팀의 손발

- **기본 손발**: 서버 브라우저는 늘 켜져 있다. 브라우저 담당(일반 러너 + Playwright MCP)이 등록한 사이트의 허용 출처 안에서 일한다. 브라우저 담당은 비공개를 읽지 않는다.
- **보기 · 로그인 · 직접 하기**: 콘솔 화면(HTTPS). 누르고 바로 입력, 한글 · 붙여 넣기 · 키 · 휠 (구현됨).
- **로그인**: 비밀번호는 어디에도 저장하지 않는다. 내가 콘솔 화면에서 한 번 로그인하고(2단계 인증 포함) 브라우저는 로그인 상태만 기억한다. 세션이 끊기면 "로그인 필요" 알림 → 콘솔 화면에서 로그인 → 이어서 한다. 사이트마다 "세션 지우기"(그 사이트의 쿠키만 지움). 자동화용 계정을 권한다. 브라우저의 비밀번호 저장은 정책으로 꺼져 있다.
- **둘러보기 모드**: 로그인이 필요 없는 조사 · 가격 비교는 일마다 새 빈 컨텍스트로 아무 공개 사이트나. 로그인된 프로필은 건드리지 않는다.
- **단계 캡처**: 일의 단계마다 화면을 결과에 남긴다.
- **결재된 클릭**: AI는 마지막 버튼(제출 · 결제 · 게시) 앞에서 멈추고 "어느 페이지의 어느 버튼 + 그때의 화면"을 남긴다. 결과 결재에서 승인하면 하네스(AI 없음)가 같은 페이지 · 같은 버튼인지 확인하고 누른 뒤 결과 화면을 남긴다. 페이지가 바뀌었으면 누르지 않고 "콘솔 화면에서 직접"으로 돌린다.
- **Mac AI 브라우저**: 서버 IP가 막히는 사이트, 사내망이 필요할 때만 쓰는 보조 (7단계에서 필요하면).

## 8. 모으기와 기억

- **Claude Code 세션**: 끝날 때 훅이 저장한다(떼어 낸 프로세스가 올림, 내 컴퓨터에서 민감정보를 지운 원문 → 서버 러너가 세션 노트). 같은 세션은 한 번.
- **소식 · 상태 줄**: `cairn connect`가 소식 기기(권한 `news`, 읽기만)를 만들고 훅 · 상태 줄을 깐다. 이미 있는 훅 · 상태 줄은 덮지 않는다.
- **브라우저 확장 (내 브라우저)**: 보고 모으기만. 정한 사이트(ChatGPT · Claude · Gemini 웹 대화)를 세션으로, "이 페이지 보관"으로 읽은 글을 보관함으로, "이 페이지로 맡기기"로 대화를. 방문 기록 전체는 모으지 않는다. 사이트별 읽는 부분은 maintainer가 점검한다.
- **기억**: 맡길 때 관련 위키를 붙인다(`cairn-recall`). 어시스턴트마다 "일마다 새로 / 앞 일의 메모 이어 받기"(`remember`).

## 9. 보관함 · 자라는 페이지 · 블로그 · 자동화

- **보관함**: 결과물 · 읽은 웹 글(탭 읽기 · 확장) · 블로그 글 · 세션 · 위키를 한 화면에. 종류 · 프로젝트 · 기간으로 거른다. 여기서 블로그에 올린다.
- **자라는 페이지**: 계속 쓸 결과물(여행지도 · 현황판). `index.html` + `data.json`, 방향(나만 고침), 판(추가만), 바뀐 점(데이터 차이), 고치기는 한 번에 하나. 공개 페이지의 새 판은 결과 결재 뒤.
- **블로그**: 하나의 블로그에 메뉴(글 목록 · 호 목록 · 페이지 모음 · 페이지 하나). 올리기 → 공개 두 단계. 메뉴마다 편집 방침 · 운영 팀 · 읽을 범위(`read_all` 없음) · RSS. 매거진은 호 단위, 발행은 호 전체를 한 번에.
- **자동화**: 레시피(언제 · 누가 · 무엇을 · 무엇으로 · 받을 것 · 어디로 · 지킬 것). 계기는 시간 · 손 · 다른 자동화 끝남 · GitHub. 결과는 결과 결재로.

## 10. 성장: 새 AI 도구 붙이기

| 붙일 것 | 길 |
|---|---|
| 스킬 · 작업 방식 | 콘솔 스킬 메뉴 (1차에서 됨) |
| 모델 · 생각 강도 | 어시스턴트 설정의 런타임 칸 |
| MCP 도구 (새 서비스) | **도구 꽂기**: MCP 서버를 등록(결과 결재) → 에이전트마다 허락 → 러너가 그 일에만 붙인다. 셸 · 비공개와 함께 두지 않는 규칙은 같다 |
| AI CLI (예: Gemini CLI) | 러너 어댑터. maintainer가 새 도구 · 새 버전을 살펴 PR로 올린다 |
| 정리 | 서버 러너의 정리 팀: 세션 정리(하루 한 번) · 위키 · 보관함 점검(매주). 더하기는 자동, 합치기 · 지우기 · 공개 전환은 확인 |

## 11. 단계

단계마다 시작할 때 인터페이스를 결재로 받고 구현 · 검사 · 배포까지 한다.

| 단계 | 내용 | 목표 | 끝났다는 기준 |
|---|---|---|---|
| **1-0** AI가 읽는 글 | 도구 설명은 모듈 설명서(`<모듈>.tools.ko.json`) + 콘솔 "도구 설명" 화면, 지시문은 러너 스킬 `cairn-runner`의 틀(스킬 메뉴에서 고침, 일마다 서버가 보냄, 실행 기록에 판). 코드에는 모양만 | 5 | 도구 설명 · 지시문을 배포 없이 콘솔에서 고치고, 어느 판으로 돌았는지 실행 기록에 남는다 |
| **1** 홈 · 대화 · 병렬 | 홈 · 대화 화면, 대표 단일 창구(콘솔 · MCP 같은 대화, 상대 생략 → 대표), 팀 카드, 덧붙이기, 소식(훅 · 상태 줄 · 소식 기기), 서버 러너 동시 실행, 가정 남기기 | 1 | 홈에서 · Claude Code에서 맡기면 팀이 동시에 일하고, 도중에 보낸 말에 대표가 답하고, 세션은 묶이지 않는다 |
| **2** 결과 결재 | 결과 결재 카드(골라서 승인 → 실행, 수정 요청 → 다음 회차), 받을 것과 검사, 검토자 짝, 한도 · 멈춤 | 1 · 2 · 4 | 결과 카드에서 고른 것만 남고, 발행을 고르면 서버가 발행하고, 검사에 떨어진 결과는 팀이 고쳐 다시 올린다 |
| **3** 서버 브라우저 목표 | 브라우저 담당, 로그인 필요 알림, 사이트 세션 지우기, 둘러보기 모드, 단계 캡처, 결재된 클릭 | 2 | 등록한 사이트에서 양식을 채우고, 결재 뒤 하네스가 제출하고 결과 화면이 남는다 |
| **4** 모으기 | Claude Code 세션 자동 저장, 브라우저 확장(웹 AI 대화 · 페이지 보관 · 맡기기 · 결재 배지) | 3 | 말하지 않아도 Claude Code 세션과 ChatGPT 웹 대화가 세션으로 쌓인다 |
| **5** 보관함 · 자라는 페이지 · 자동화 | 보관함, 자라는 페이지, 자동화 레시피 | 4 | 보관함에서 종류별로 거르고, 여행지도가 매주 새 판이 된다 |
| **6** 블로그 메뉴 · 매거진 | 메뉴 네 종류, 올리기 → 공개, 매거진 호 | 4 | 보관함에서 고른 결과물이 메뉴로 공개되고, 매거진 호가 결재 한 번으로 나간다 |
| **7** 성장 | 도구 꽂기, 모델 설정, CLI 어댑터, maintainer 순환, 정리 넓히기, (필요하면) Mac AI 브라우저 | 5 | 새 MCP 도구를 결재 한 번으로 붙이고, maintainer가 CLI · 스킬 · 확장을 고치는 PR을 올린다 |

## 12. 지키는 것

- 원칙 1~7 그대로 ([AGENTS.md](../AGENTS.md)). 위험한 동작은 결과 결재 뒤에 믿는 코드가 실행한다. AI가 직접 발행 · 전송 · 삭제 · 제출하지 않는다.
- 비밀번호는 저장하지 않는다. 비밀(GitHub 토큰 · AI 로그인)은 하네스 메모리에만.
- 브라우저 담당 · 둘러보기 · 셸이 있는 러너에게 비공개를 주지 않는다.
- 내 브라우저에서 AI는 클릭하지 않는다 (확장은 보고 모으기만).
- 조종 포트(CDP)는 밖으로 열지 않는다. 서버 브라우저 화면은 관리자만.

## 13. 바뀌는 1차 결정

| 1차 결정 | 2차 | 단계 |
|---|---|---|

| 대화 상대는 관리자 바로 아래 에이전트, 답을 기다리는 동안 보내지 못함 | 대표 단일 창구, 일하는 중에도 보낸다 | 1 |
